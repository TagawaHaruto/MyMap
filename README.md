# MyMap — 休日おでかけ検索

起点（初期設定：調布駅）から半径 300km（関東・甲信越・東海・南東北の一部）の遊び場・観光地・乗り物スポット・博物館・植物園・寺社・温泉・絶景・ショッピング・イベント・ツーリングルートを探せるスマホ用 Web アプリ（PWA）です。AI や有料サービスは使わず、無料で動きます。

## できること
- **スポット**（観光スポット・体験・グルメ・史跡・宿・お土産・遊び。範囲は `config.json` の `poiRadiusKm`）：移動手段（電車・車・バイク・自転車）と時間、都県、方面（北・西など）、ジャンルで絞り込み。★厳選と⭐お気に入りを先頭に表示
- **名前で検索**：ひらがな・カタカナ・全角半角の違いを無視（例：「じんだいじ」で深大寺）。「ラーメン」「ハンバーグ」「カフェ」など料理のジャンルでも探せる
- **入力補完**：検索欄に入れている途中で候補（料理のジャンル・「近くの○○」・スポット名、ネットでは OpenPOI の候補）を表示
- **ホーム画面のショートカット**：アイコンを長押しして「近くの飲食店」「近くのカフェ」「ツーリング」「おまかせ」をすぐ開く（Android。iPhone は未対応）
- **近くの○○**：検索欄に「近くの飲食店」「近くのカフェ」「温泉 近く」などと入れると、現在地（使えなければ起点）から 3km 以内を近い順に（アプリ内のデータ＋OpenPOI）
- **ネットの施設検索（OpenPOI API）**：検索欄・ツーリングの目的地検索・日帰りプランの「行き先を追加」で、手元のデータにない施設も日本全国約337万件（Overture Maps・食品営業許可のオープンデータ）から探す。キー不要・無料
- **地図で見る**：一覧・検索結果を地図に種類の絵文字（🏯⛩♨🍴🚗など）のピンで表示（★厳選は金色の縁。押すと経路・写真・口コミ）
- **種類の「🌐すべて」**：観光・遊びに加えて、グルメ・史跡・宿・お土産・遊びも全部まとめて表示
- **営業中の表示**：営業時間がわかる所は「営業中／営業時間外」を表示。「🕘営業中だけ」で絞り込み
- **時間帯で絞り込む**：🌅朝・☀昼・🌇夕方・🌙夜・🌌深夜。営業時間が分かる所はその時間帯に開いているか、分からない所は夜・深夜だけ屋外の展望台・夜景・湖・海岸と道の駅（駐車場・トイレは 24 時間）に絞る（庭園・入場料のかかる所・屋内は出さない。夜景の展望室は夜だけ）
- **🔭展望台・🌃夜景**：「観光」「絶景」とは別の種類に。夜景スポット（都庁・お台場・大黒PA・海ほたる・工場夜景・甲府盆地など約 40 か所）を厳選に追加
- **☕ちょっとお出かけ・🌙夜も遊べる**：調布の近くで1〜2時間で楽しめる場所（公園・小さな博物館・銭湯・直売所など）と、夜遅く・深夜まで開いている温浴施設・ボウリング・プラネタリウム・展望台・書店などを調べて追加（営業時間つき。時間帯の絞り込みにも反映）
- **車で走るコース**：二輪が通れない道（鋸山登山自動車道・多摩湖周回・間瀬峠）は「🚫二輪通行不可」と理由を表示
- **今が見頃**：桜・紅葉・花などの見頃の月を表示。「🌸今が見頃」で絞り込み
- **日帰りプラン**：「▼詳しく」→「日帰りプラン」で、出発 → 目的地 → 近くで昼食 → 温泉など → 帰着の予定を自動で作成（Google マップで 1 日の経路・共有）。行き先の追加（名前・料理で検索／近くのおすすめ）・外す・並べ替え・滞在時間の変更、帰宅したい時刻に間に合うかの表示と「時間内に収める」。「💾 このプランを保存」で端末に保存し、一覧の上の「📋保存したプラン」から開く・編集・削除
- **お店の駐車場**：推定はせず、確かな情報だけを表示（厳選スポットの登録情報、お店の名前が入った駐車場が 150m 以内にある「🅿専用駐車場あり」、設定タブで Google の API キーを入れた場合は Google マップの駐車場情報〔無料・有料・立体・路上など〕）。「🅿駐車場あり」で絞り込み
- **🅿駐車場**：「▼詳しく」の🅿ボタンで、その施設の駐車場らしい所と、周辺の 🏍バイクを止められる所（3km 以内）・🏍止められるかもしれない所（未確認。利用者用や 50 台以上・コインパーキング除く）・🚗車の駐車場（1km 以内）を近い順に（各 20 件＋もっと見る）。OpenStreetMap の駐車場（起点から 150km 圏）とバイク関連は週 1 回まとめて収集し、その場の検索・OpenPOI・道の駅・SA・PA も合わせる。ツーリングの「🅿目的地の駐車場」、立ち寄り候補の吹き出し、検索欄の「近くの駐車場」「近くのバイク駐車場」からも
- **周辺を探す**：「▼詳しく」からコンビニ・トイレ・駐車場・バイク駐車場・ガソリンスタンド・EV充電・ATM・カフェを近い順に
- **交通費の目安**：「▼詳しく」に起点から往復の電車の運賃（JR の運賃表で概算）とガソリン代、日帰りプランに 1 日の交通費
- **ストリートビュー・電話・共有・車いす対応**：「▼詳しく」から
- **地図**：航空写真・地理院地図・山の陰影に切り替え。◎で現在地（青い点と精度の円・移動に合わせて動く）。青い点を押して「ここから出発（起点にする）」
- **行った場所の記録**：設定タブに、行った場所の地図と都県ごとの数
- **起点を現在地に**：設定タブで切り替え（移動時間・ルートを現在地から計算）
- **⏱今から行ける**：車・バイク・自転車で、実際の道のりで移動時間内に着ける範囲だけに絞り込み（地図に範囲を表示）
- **天気で選んだ週末プラン**：土日の午前・午後の降水確率で、晴れなら屋外、雨なら屋内のスポットを自動で割り当て
- **日の出・日の入り・ダイヤモンド富士**：「▼詳しく」に今日の日の出・日の入りの時刻と方角、富士山の方向の場所ではダイヤモンド富士の日と時刻（予測）
- **混みやすさの目安**：週末・祝日・大型連休・見頃の時期から（実際の混雑ではありません）
- **お気に入りの共有**：設定タブから、⭐お気に入りを 1 本のリンクで家族に送る
- **🧭まだ行っていない方面**：行った記録の少ない方面のスポットを、今週末のおすすめの下に提案
- **写真**：Wikipedia（記事がなければ施設名で探し、3km 以内の記事だけ。付近の記事は「関連する記事」と表示）、Wikimedia Commons（施設名と付近 1km 以内）で探す。設定タブで自分の Google の API キー（Places API (New)）を入れると Google マップの写真も表示（キーは端末の中だけ・写真は保存しない）
- **🎲おまかせ**：今の絞り込み条件の候補からランダムに 1 か所（「もう一回」で引き直し）
- **説明と写真**：「▼詳しく」で Wikipedia の説明と写真、なければ付近の写真（Wikimedia Commons）。Google マップで写真・口コミを見るボタンつき
- **雨の日モード**：週末の天気を見て自動で ON（屋内のみ表示）
- **🎨体験**（陶芸・ガラス工房、カート・サーキット、ボルダリング、脱出ゲーム、果物狩り・牧場など）。「当日参加OKだけ」で予約不要の所に絞り込み
- **🎮シミュレーター**（フライト・ドライビング・電車の運転など）が体験できる施設で絞り込み
- **今週末のおすすめ** 3 件
- **イベント**：近隣自治体・施設のイベント一覧。募集・講座などの告知は隠せる
- **ツーリング**
  - 走り方の選択：有料道路を使わない／高速道路をなるべく使わない／バイク向け
  - ルート候補を最大 5 本並べて、時間・距離・有料の有無・景色★で比べる
  - 走って楽しい道・景色の良い道（厳選）を寄り道として通す候補、または道を選んで調布に戻る周回
  - ドライブコース（OpenStreetMap の名前付きの観光道路・林道など）と峠を地図に表示し、押して「このコースを走る」。目的地の検索欄でもコース名・峠名で探せる。種類ごとに色分け（★おすすめ・スカイライン・峠道・海沿い・高原・有料・林道〔点線〕・峠）し、凡例を押して出す・隠す。同じ種類でも 1 本ずつ少しずつ色を変え、両端に白い丸を付けて区切りが分かるように。「🌙夜も走れる道だけ」で夜間通行止めの道を外し、夜景の道を太く表示
  - 🔗コースをつなげる：地図のコースを押して「🔗つなげる」で複数のコースを選び、順番を入れ替えて「この順で続けて走る」（例：C1一周→夜景周回）。首都高どうしなら高速道路の上の地点でつなぎ、分岐の案内も通しで出る
  - 全画面の地図：ツーリングは地図を画面いっぱいに出し、目的地・ルート候補・立ち寄りなどは下から引き出すパネル（つまみを押すかドラッグで 低い／半分／高い）。上に目的地と距離・時間・「ナビ」。右上の「☰」で今までの表示に戻せる（「⤢ 全画面」で戻る）。つなげたコースは名前を付けて保存でき、目的地の一覧から選べる
  - 📌Google マップのルートを登録：Google マップで作った経路の共有リンク（maps.app.goo.gl）を貼ると、経由地の位置を読み取って目的地に登録（端末の中にだけ保存。短縮リンクの展開に外部の中継 allorigins を使う）
  - 首都高などの高速道路のコース（C1・C2 一周、夜景周回、湾岸線など）：ルート検索で高速道路だけに合わせて途中で降りないようにし、「🔀分岐（JCT）の案内」で走る順にどの JCT でどちらへ進むか（OpenStreetMap の標識から）を表示。Google マップには、下や横に一般道・ランプがない高速道路の上の地点だけを経由地として渡し、同じ距離になるかで確かめられる
  - 道沿いの立ち寄り候補（道の駅・温泉・展望台・滝・湖など）。地図の点を押すと写真と説明
  - 交通費の目安：ガソリン代（燃費・単価は設定タブで変更）と高速料金（有料区間の距離から NEXCO の式で概算）、往復の合計
  - 出発時刻と到着予定、ルート上の雨（通過する時刻の降水確率）、標高グラフ、ルート沿いの写真
  - ルート候補ごとのカーブの多さ（★）、カーブの多いコースの一覧、方面別の雨、閉鎖・通行止めの道の警告と一覧
  - 走行記録（GPS。距離・時間・最高地点、GPX で保存）
  - ⛽24時間ガソリンスタンド：ルートから 1km 以内の 24 時間営業のスタンドを走る順に、通過する時刻の目安と地図の ⛽ で。高速道路を走っている区間の近くは「一度降りて給油」の印（OpenStreetMap で 24 時間営業と登録されている所。週 1 回収集）
  - ♨帰りに寄れる温泉（ルートから 3km 以内を家に近い順に。着く時刻と、その時刻に営業中か）
  - 圏外用にルート沿いの地図（地理院地図）を端末に保存
  - Google マップでナビ開始（選んだルートから外れないよう経由地を自動で追加）、GPX で保存
- **画面のデザイン**：スタイリッシュ（既定。グラデーション・丸みのあるカード。端末がダークモードなら暗い配色）と、標準（デジタル庁デザインシステムに沿った表示）を設定タブで切り替え
- **屋外モード**（☀屋外）：日なた・グローブ向けに文字とボタンを大きく太く。ツーリングを開くと自動で ON
- **圏外でも**：一度開いたデータ・ルートは端末に残り、圏外でも表示できる

## 家族・ほかの端末で使う（インストールのしかた）
アプリストアではなく、**リンクを開いて「ホーム画面に追加」**するだけで入ります（無料・登録不要）。

- アプリの「設定」タブ →「ほかの端末・家族に入れる」に **QR コード**と「リンクを送る」ボタンがあります。リンク：`https://<ユーザー名>.github.io/<リポジトリ名>/`
- 初めてスマホで開いたときは、画面の上に端末に合わせた入れ方が出ます（Android の Chrome はボタン 1 つで入ります）。

| 端末 | 入れ方 |
|---|---|
| iPhone / iPad | リンクを **Safari** で開く → 共有ボタン（□↑）→「ホーム画面に追加」→「追加」 |
| Android | リンクを **Chrome** で開く → ︙ →「アプリをインストール」（または「ホーム画面に追加」） |
| パソコン | Chrome / Edge のアドレスバーのインストールのアイコン、またはメニュー →「アプリをインストール」 |

- LINE などのアプリの中で開いたときは、まず「Safari で開く」「ブラウザで開く」にしてください。
- お気に入り・行った記録・保存したプランは端末ごとに別々です（お気に入りは設定タブの「お気に入りの共有」で送れます）。
- 家族の端末では、トークンや API キーの設定は不要です（データの更新は持ち主の設定で自動で行われます）。

## スマホで使う（このリポジトリの持ち主）
1. **リポジトリを公開にする**：GitHub のリポジトリ画面 → **Settings → General** の一番下 **Danger Zone → Change visibility → Make public**。
   - 無料プランの GitHub Pages は公開リポジトリでしか使えません。公開されるのはアプリとスポット・イベントのデータだけです（お気に入り・行った記録・トークンはスマホの中にだけ保存され、公開されません）。
2. **Pages を有効にする**：**Settings → Pages** → Source を「Deploy from a branch」、Branch を **`gh-pages`** / `/ (root)` にして **Save**。1〜2 分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開けるようになります。
   - `gh-pages` は Actions が「アプリ＋最新のデータ」を組み立てて毎回上書きする公開用のブランチです（約10万件のデータを `main` の履歴に積まないため）。`main` を更新すると自動で作り直されます。
3. **スマホで開いてホーム画面に追加**
   - iPhone（Safari）：共有ボタン（□↑）→「ホーム画面に追加」
   - Android（Chrome）：右上の ⋮ →「ホーム画面に追加」または「アプリをインストール」
4. **データの自動更新（アプリの中だけで完結）**：アプリの **設定タブ →「データの更新」→「トークンの登録」** の手順で、GitHub のトークンを一度だけ登録します（Actions の Read and write だけ・このリポジトリだけ）。
   - 以後は**アプリを開くだけ**で、データが古いとき（`staleHours`）や、前回の収集で時間切れの種類が残っているときに、自動で収集を依頼します。収集中は進み具合が出て、終わると自動で新しいデータに切り替わります。GitHub での操作は不要です。
   - 「今すぐ更新」「トークンを確認」も設定タブにあります。トークンは端末の中にだけ保存されます。家族の端末には不要です。

### 使い方のコツ
- ナビは **Google マップのアプリ**で開いてください（ブラウザ版の Google マップは経由地が 3 件までしか使えません）。「有料道路を使わない」を選んだときは、Google マップ側の「ルートオプション」でも同じ設定にしてください。
- 走行中は画面を見ないでください。ツーリングタブは停車中に使う前提です（走行中の案内は Google マップの音声ナビに任せます）。
- 日なたでは「☀屋外」に。端末の明るさの自動調整をオンにし、反射防止フィルムを貼るとさらに見やすくなります。

## 自分用にコピーして使う（ほかの人）
1. このリポジトリの **Use this template → Create a new repository** で自分のアカウントにコピーする（Public）。
2. `config.json` を書き換える。
   - `origin`：起点の名前と緯度・経度（Google マップで地点を長押しすると表示されます）。
   - `github`：通常は書き換え不要（持ち主の名前は公開 URL から自動で判定。リポジトリ名を変えたときは `repo` も）。
   - `sources`：イベントの収集元。地元の自治体サイトの `/event.js` があれば `"type": "eventjs"` で 1 行追加できます。
   - `directionLabels`：方面の表示名（例 `"W": "西（奥多摩・山梨）"`）。
3. **Settings → Actions → General → Workflow permissions** を「Read and write permissions」にする。
4. 上の「スマホで使う」の 2〜4 を行い、**Actions タブ → collect → Run workflow** で初回のデータ収集を行う（5〜15 分）。

## データについて
- `data/spots.json`・`data/touring.json`・`data/scenic_roads.json`：手作業で選んだスポット・ツーリング目的地・おすすめの道。自由に追加・編集できます。
  おすすめの道（302本）のうち 90 本は、2026年10月に自治体・道路管理者などの公開情報を調べて追加したもので、各コースに出典（`sources`）と注意事項（`alerts`。通行止めなどの年月つき）があります。線は通過点をルート検索で実際の道に沿わせて確かめています。
- `data/osm_spots.json`・`data/pois.json`・`data/cells/`（グルメなどを約 25km 四方の升目ごとに分けたもの）：OpenStreetMap から週 1 回自動収集。料金や駐車場の情報はありません。これらは `gh-pages` にだけ置かれます。
- `data/events.json`・`data/status.json`：自動生成。手で編集しないでください。
- `data/jct.json`：分岐の案内に付ける JCT の名前と位置（OpenStreetMap）。`data/scenic_roads.json` の `hw` は高速道路のコースの案内用の点（高速道路の上・JCT から離れた所）
- `data/prefectures.json`：都県の判定用の境界（OpenStreetMap を簡略化したもの）。関東周辺の 10 都県のみ（それより外は「その他」）。
- バイク駐車場の公式データ：東京都内の区市（中央区・品川区・八王子市・調布市・町田市・杉並区など 20 区市）のオープンデータ（CC BY 4.0。`data/moto_official.json`、各件に出典）
- 駐車場の一部：Foursquare OS Places（© Foursquare Labs, Inc.・Apache-2.0・2025年2月版。`data/park_fsq.json` は名前と位置だけに加工。`licenses/` に NOTICE と Apache License）
