## 共通の取得方法

- データセット探索: 東京都オープンデータカタログ CKAN API
  `GET https://catalog.data.metro.tokyo.lg.jp/api/3/action/package_search?rows=1000&q=<語>`（二輪, 自動二輪, オートバイ, バイク, 原付, 原動機付自転車, 駐輪場, 自転車駐車場, 自転車等駐車場, 駐車場, 駐輪, 自転車置場 など）
  メタデータ: `GET https://catalog.data.metro.tokyo.lg.jp/api/3/action/package_show?id=<datasetId>`
- API カタログのデータ取得（spec ページは Swagger 2.0。GET ではなく **POST**）:
  ```
  POST https://service.api.metro.tokyo.lg.jp/api/<apiId>/json?limit=1000&offset=0
  Content-Type: application/json
  body: {}
  ```
  レスポンス `{total, hits:[...], metadata:{updated,...}}`。total>1000 の場合は offset でページングする。
  **apiId = `<datasetId>-<md5(リソースURL文字列)>-0`**（例: md5("https://www.city.chuo.lg.jp/documents/984/kuei_nirinsha.csv") = a9033dfe…）。リソースURLが変わると apiId も変わるので、週次で再取得するときは package_show でリソースURLを取り直して apiId を再計算するのが確実です。
- API に載っていないもの（404）は、リソースURLの CSV / XLSX / ZIP を直接ダウンロード（UTF-8 か Shift_JIS）。
- ネットワーク: `node --use-system-ca` の fetch を使用（Python の HTTPS は SSL インスペクションで失敗する）。
- ジオコーディング: 座標がない行は GSI `https://msearch.gsi.go.jp/address-search/AddressSearch?q=<住所>` を使用（12件）。住所がない行は GSI 逆ジオコーダ `https://mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress?lat=&lon=` で「東京都<区市>町丁目付近」を補完（51件。addr が「…付近」で終わるもの）。座標は小数5桁に丸め。
- 同名かつ約50m以内の重複は除去。fee は200文字で切り詰め。
- 判定ルール: moto = 自動二輪（50cc超）可、moped = 原付（50cc以下）可。「バイク」とだけ書かれ排気量区分がない場合は moto=true, moped=true（推定）。「125ccまで」「〜125」は 51〜125cc を含むので moto=true とする。
- ライセンス: 使用した全データセットのカタログ license_id は CC-BY-4.0（出力では "CC BY 4.0"）。
- 処理スクリプト（再実行用、セッション一時領域）: `…\scratchpad\moto\fetchall.js`（取得）, `build.js`（解析）, `finalize.js`（ジオコーディング・出力）
